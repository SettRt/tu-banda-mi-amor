# Gonzalo Genek x Guerreros del Bajo

Sitio web estatico listo para publicar en GitHub Pages.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseno, responsive y animaciones.
- `script.js`: menu movil, animaciones al hacer scroll y marquee.

## Musica

La cancion "Ella" esta integrada con el reproductor oficial de Spotify para respetar derechos de autor. Los navegadores suelen bloquear el autoplay, por eso el visitante debe presionar play.

## Publicacion

Sube estos archivos a un repositorio de GitHub y activa GitHub Pages desde `Settings > Pages`.
